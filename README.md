# C13

C13 is a work-in-progress client for the [Deep Space Communication Relay (DSCR)](https://github.com/dixonary/mfds-server).

It is written largely as a learning exercise, to ~~confront fear and ignorance towards frontend development~~ learn the Qt framework.

C13 is very much in an alpha state of development and features less usability than [other](https://github.com/electraminer/relay3544) [DSCR](https://github.com/A5TR0spud/dscr_asterclient/) [clients](https://github.com/dixonary/mfds-server).

## Features
- A chatbox with live signal compilation feedback
- A basic dictionary editor
- Hover tooltips and hyperlinks over signal text
- A database that stores chat history and versions each modification to a translation
